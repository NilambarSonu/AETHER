# Changelog

## [1.0.0] - 2026-11-10

- Built against the official DroppyKit SwiftPM SDK (`1.12.0`+ compatible with Droppy 15.3+, Droppy Playground, and Droppy 16.x).
- Added the `HUDPresenting` notch presentation bridge for ephemeral verification codes delivered by the local AETHER host over kernel-authenticated Unix Domain Sockets.
- Added primary one-click clipboard copy (`Copy Code`) and explicit `Dismiss` actions alongside `.displayed` and `.copied` host acknowledgments.
